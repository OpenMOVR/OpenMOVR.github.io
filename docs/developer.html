Getting Started

  1. Choose your project - Website (HTML/CSS/JS) or Analytics (Python)
  2. Fork the repository on GitHub
  3. Read the CONTRIBUTING.md in each repo
  4. Set up your environment (see each project below)
  5. Create a feature branch and submit a PR

Code Standards

Website (HTML/CSS/JS)

  • Semantic HTML5 elements
  • CSS variables for consistency
  • Vanilla JavaScript (no frameworks)
  • Mobile-first responsive design
  • 2-space indentation

Analytics (Python)

  • Type hints required
  • Black formatter
  • MyPy type checking
  • Pytest for testing
  • Docstrings for public APIs

Common Tasks

Adding a New Page

  1. Create HTML file in appropriate directory
  2. Link css/main.css and use its classes; avoid inline styles
  3. Add <div id="header-placeholder"></div> at the top of the body and <div id="footer-placeholder"></div> at the end
  4. Load js/config.js, js/main.js and js/header-loader.js, in that order
  5. Add the page to js/config.js so it appears in the navigation, and to components/footer.html
  6. A page in a new subfolder needs that folder added to SUBDIRS in header-loader.js

Updating Statistics

Every figure on progress.html comes from data/progress.json. Edit the numbers and the updated date there; percentages are computed from the counts. Each block keeps its population, source and dates, so a figure is never published without them.

The homepage stats are written in index.html, in the "MOVR Data Hub at a glance" panel, and must match the Community Snapshot.

Updating the front door

data/front-door-today.json holds the real figures shown on front-door.html; data/front-door-sample.json holds the labeled sample view. Groups under suppress_below are never shown.

Testing Checklist

  • Test locally (./launch.sh)
  • Test on mobile (browser dev tools)
  • Check all links work
  • Verify no console errors
  • Update documentation if needed

OpenMOVR App

Live App | github.com/OpenMOVR/openmovr-app | Changelog

Interactive MDA MOVR Study Analytics Dashboard

Streamlit-based web application for exploring MDA MOVR Study data. Built for researchers, clinicians, and data analysts to understand disease cohorts, facility distributions, and data completeness across the MOVR registry.

The current release is v0.3.0 (2026-09-28). It adds the public Community Snapshot page and a data provenance banner. Every page now states the data extract date, the statistics generation date and the app version.

Quick Start

# Clone the repository
git clone https://github.com/OpenMOVR/openmovr-app.git
cd openmovr-app

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run locally
streamlit run app.py

# Visit http://localhost:8501

Features

Community Snapshot

  • Study-wide demographics across all seven diseases
  • Health insurance overall, by disease, by disease group and by age at enrollment
  • Methods covering the source field, denominators, multi-select handling and small-cell suppression
  • Suggested citation, plus CSV/JSON downloads

Dashboard

  • Database overview statistics
  • Participant counts by disease
  • Facility distribution map
  • Demographics analysis

Disease Explorer

  • Filter by diagnosis (DMD, SMA, ALS, LGMD, etc.)
  • Real-time cohort analysis
  • Age and gender distributions
  • Disease subtype breakdown

Data Dictionary

  • Browse MOVR data fields
  • Filter by disease and form
  • Data completeness metrics
  • Field descriptions

Clinical Analytics

  • DMD, LGMD, ALS and SMA pages
  • Organized by clinical domain
  • Summary tables in public snapshot mode
  • Full detail requires a signed DUA

Architecture

The app uses a dual-mode architecture:

Snapshot Mode (default):
- Uses pre-computed JSON statistics
- No parquet files needed
- Fast loading, limited interactivity
- Safe for public deployment

Live Mode (with data):
- Uses parquet data files
- Full filtering and real-time calculations
- Complete interactivity
- Requires data access

Deployment

To Streamlit Cloud (Recommended)

  1. Push to GitHub: git push origin main
  2. Go to share.streamlit.io
  3. Click "New app" and select this repo
  4. Set main file to app.py
  5. Click "Deploy"

Default URL: openmovr-app.streamlit.app

Custom Domain: Configure in Streamlit Cloud settings

Data Handling

Snapshots (stats/*.json)

  • Pre-computed aggregate statistics
  • No PHI - safe to commit and deploy
  • Updated manually when data changes

Parquet Files (data/*.parquet)

  • Raw registry data (may contain PHI)
  • .gitignored - never commit to public repos
  • For private deployment with full interactivity

Regenerating Snapshots:

python scripts/generate_stats_snapshot.py   # includes community_profile
python scripts/generate_{dmd,lgmd,als,sma}_snapshot.py
python scripts/generate_curated_dictionary.py

Development

Adding a New Disease Page

  1. Create scripts/generate_{disease}_snapshot.py
  2. Create api/{disease}.py with API class
  3. Create pages/X_{Disease}_Clinical_Analytics.py
  4. Update api/__init__.py exports

movr-datahub-analytics

github.com/OpenMOVR/movr-datahub-analytics | Full Documentation

GSoC 2026 Priority Project

Python package for analyzing MOVR DataHub (2019-2025) registry data. Ideal for students interested in healthcare data analytics.

Quick Start

# Clone the repository
git clone https://github.com/OpenMOVR/movr-datahub-analytics.git
cd movr-datahub-analytics

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# Install with all dependencies
pip install -e ".[dev,viz,notebooks]"

# Setup configuration
movr setup

# Verify installation
movr --help

Key Features

Data Pipeline

  • Excel to Parquet conversion
  • YAML-configurable wrangling rules
  • Audit logging

Analysis Tools

  • Cohort management
  • Descriptive analytics
  • Data dictionary search

CLI Commands

# Setup configuration
movr setup

# Convert Excel to Parquet
movr convert

# Validate data quality
movr validate

# View statistics
movr summary --registry datahub --metric all

# Search data dictionary
movr dictionary search "age"
movr dictionary search "medication" --diseases "DMD,SMA"

Development

# Run tests
pytest

# Format code
black src/ tests/

# Type checking
mypy src/

# Pre-commit hooks
pre-commit install
pre-commit run --all-files

For complete documentation including architecture, API reference, and contribution guidelines, see the DataHub Analytics Documentation.
