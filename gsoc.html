Project ideas

Where you can contribute

Our priority is making MOVR's legacy data easy for researchers anywhere to access and analyze.

Priority project Intermediate

MOVR Legacy DataHub Python library

Repository: movr-datahub-analytics. Create a pip-installable library that makes twelve years of MOVR registry data (2013–2025) easy for researchers, universities and data scientists to load and analyze.

What you'll build

  • Simple data loading: movr.load_dataset('ALS')
  • Disease modules for ALS, DMD, SMA, BMD, LGMD, FSHD and Pompe
  • Clean pandas DataFrames, ready for analysis
  • Longitudinal tools to follow disease progression
  • Plotting utilities and scikit-learn / PyTorch support
  • Jupyter tutorials and research templates

Example usage

pip install movr-datahub

import movr_datahub as movr

als = movr.load_dataset('ALS', include_longitudinal=True)
print(f"Loaded {len(als)} ALS participants")

progression = movr.analyze_progression(als, metric='ALSFRS_R')
movr.plot_progression(progression, save='analysis.png')
Deliverables: a production package on PyPI, API documentation, 10+ tutorial notebooks covering common research questions, unit and integration tests, and worked example analyses.
